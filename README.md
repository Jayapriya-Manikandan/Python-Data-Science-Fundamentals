# Python Data Science Fundamentals

A beginner-friendly Python and Data Science project for analyzing personal expenses.

## Features

- Analyze expense data using Pandas
- Calculate total and category-wise spending
- Analyze payment methods
- Generate expense reports
- Create visualizations using Matplotlib

## Project Structure

Python-Data-Science-Fundamentals/
│
├── data/
│   └── expenses.csv
│
├── src/
│   ├── expense_analyzer.py
│   ├── data_analysis.py
│   └── report_generator.py
│
├── outputs/
│   ├── category_spending.png
│   ├── payment_methods.png
│   └── expense_report.txt
│
├── README.md
├── requirements.txt
└── .gitignore

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the data analysis:

python src/data_analysis.py

Generate the expense report:

python src/report_generator.py

## Output

The project generates:

- Category-wise spending chart
- Payment method chart
- Expense summary report
